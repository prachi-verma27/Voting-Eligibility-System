# Voting Eligibility System

## Project Details
PS No.: 24
Language: Python 3

## Description
This project checks whether a person is
eligible to vote based on age and
Indian citizenship.

## Features
- Checks voting eligibility.
- Validates age from 0 to 120.
- Handles invalid age inputs.
- Checks multiple voters.
- Displays final voter statistics.

## Concepts Used
- Python Functions
- If-Else Conditions
- While Loops
- Exception Handling

## How to Run
1. Download the Python file.
2. Open the terminal.
3. Run:

python voting_eligibility_system.py
